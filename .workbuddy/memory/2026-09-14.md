# 2026-09-14

## zjzPhoto 项目 Cloudflare Pages 部署改造

- 项目为纯前端 Vite 证件照工具（`base:'./'` 相对路径、模型/WASM 全部 `public/` 自托管，无后端、无 COOP/COEP 需求）。
- 为 Cloudflare Pages + GitHub 自动部署完成以下配置改造：
  1. `.gitignore`：新增 `public/models/*`、`public/wasm/*` 忽略规则（保留 `.gitkeep`），防止 25MB+ 模型入库；同时忽略 `.env`、测试产物。
  2. `package.json`：`build` 脚本改为 `npm run fetch:models && tsc --noEmit && vite build`，确保 CI 无本地缓存时先拉取并校验模型（sha256）。
  3. 新增 `public/_headers`：模型/WASM `immutable` 长缓存 1 年+，`assets/*` 长缓存，HTML 不缓存 + 安全头。
  3. 新增 `public/_headers`：模型/WASM `immutable` 长缓存 1 年+，`assets/*` 长缓存，HTML 不缓存 + 安全头。
  4. 新增 `wrangler.toml`：**初始误用 Pages 语法 `[pages] build_output_dir`，Cloudflare 控制台创建的是 Workers 类型项目（构建后跑 `wrangler deploy`），导致部署报错 "Failed: error occurred while running deploy command"。已改为 Workers + Static Assets 语法：`[assets] directory = "./dist"` + `not_found_handling = "single-page-application"`**（`npx wrangler deploy --dry-run` 验证通过）。
- 已验证：`npm run build` 成功（模型 sha256 全过），dist 产物 13 文件 34.5MB，含 `_headers`、模型、WASM；入口用相对路径，挂根路径/子路径均可。
- 注意：playwright 留在 devDependencies（仅 test:e2e 用），CI 构建需避免其 postinstall 下载浏览器（Cloudflare 构建一般能跳过；如需完全避免可设 `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` 或移到可选依赖）。
- 遗留：git 仓库已 init 为 main，尚未 commit/push；wrangler.toml 的 `compatibility_date` 可按需更新。
